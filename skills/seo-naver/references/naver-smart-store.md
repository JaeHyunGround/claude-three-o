# Naver Smart Store Product SEO

## Product Listing Optimization

| Field | Importance | Best Practice |
|-------|-----------|---------------|
| Product name | Critical | Category keyword + brand + specific attribute |
| Category | Critical | Most specific sub-category available |
| Price | Critical | Competitive, Naver compares across stores |
| Main image | Critical | White background, 1000x1000px minimum |
| Detail images | High | 5+ images showing different angles |
| Product description | High | 500+ characters with specifications |
| Options/variants | Medium | Complete size/color/option listing |
| Shipping | Medium | Free shipping preferred by algorithm |
| Return policy | Medium | Generous policy improves ranking |

## Smart Store Feed Format

Required fields for Naver Shopping EP (EP = Exchange Protocol):

```
id              - Unique product ID
title           - Product name (max 100 chars)
price_pc        - PC price (KRW)
price_mobile    - Mobile price (KRW)
link            - Product page URL
image_link      - Main image URL (1000x1000 recommended)
category_name   - Naver category path (e.g., "패션의류 > 여성의류 > 원피스")
naver_category  - Naver category code
shipping        - Shipping cost (0 for free)
condition       - new / refurbished / used
availability    - in stock / out of stock / preorder
```

## Ranking Factors

1. Sales volume (recent 30 days)
2. Review count and average rating
3. Product information completeness
4. Naver Pay support
5. Price competitiveness
6. Shipping speed and cost
7. Return/exchange rate (lower is better)
