# Naver Blog Optimization Guide

## Blog Ranking Signals

| Signal | Weight | Optimization |
|--------|--------|-------------|
| Recency | High | Post consistently 2-3x/week |
| Content length | High | 1500+ Korean characters per post |
| Image count | Medium | 5+ original images per post |
| Video inclusion | Medium | Embed Naver TV or YouTube |
| Engagement | High | Encourage comments and likes |
| Blog authority | High | Build visitor count over time |
| Keyword placement | Medium | Title, first paragraph, subheadings |

## Content Best Practices

- Title: 15-30 Korean characters, keyword-first
- Opening: State topic and value within first 2 sentences
- Structure: Use subheadings every 300-500 characters
- Images: Original photos preferred over stock (Naver detects)
- Conclusion: Summarize with CTA (visit, call, book)
- Tags: 5-10 relevant tags per post
- Map: Embed Naver Map for location-related posts

## Posting Schedule

| Industry | Optimal Frequency | Best Days |
|----------|-------------------|-----------|
| Restaurant | 3-4x/week | Tue-Thu (pre-weekend search) |
| Clinic | 2-3x/week | Mon-Wed (appointment planning) |
| Academy | 2x/week | Sun-Mon (enrollment period) |
| E-commerce | Daily | Product launch timing |

## Common Mistakes
- Copy-pasting from website (duplicate content penalty)
- Over-optimization / keyword stuffing
- Using only stock images
- Inconsistent posting schedule
- Ignoring comments and engagement
