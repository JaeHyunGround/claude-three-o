# Naver Place Optimization

## Listing Completeness Checklist

| Field | Required | Impact |
|-------|----------|--------|
| Business name | Yes | Must match official registration |
| Category | Yes | Select most specific sub-category |
| Address | Yes | Exact match with business registration |
| Phone number | Yes | Primary business phone |
| Operating hours | Yes | Include holiday schedules |
| Description | Yes | 200+ characters describing business |
| Photos | Yes | 10+ photos (interior, exterior, products) |
| Menu/Services | Recommended | Complete with prices |
| Booking link | Recommended | Naver Booking integration preferred |
| Website URL | Recommended | Link to official website |
| SNS links | Optional | Blog, Instagram, etc. |

## Review Management

| Metric | Target | Impact |
|--------|--------|--------|
| Average rating | 4.5+ | High ranking signal |
| Review count | 50+ | Trust and ranking signal |
| Response rate | 100% | Shows active management |
| Response time | Within 24h | Engagement signal |
| Photo reviews | 30%+ of total | Higher quality signal |

## Local Ranking Factors

1. Distance from searcher
2. Review count and quality
3. Business information completeness
4. Category relevance
5. Naver Blog/Cafe mentions
6. Recent activity (new photos, responses)
7. Booking/reservation volume

## Industry-Specific Priorities

| Industry | Priority Fields |
|----------|----------------|
| Restaurant | Menu + prices, food photos, operating hours |
| Clinic | Doctor profiles, specializations, appointment booking |
| Academy | Courses, schedule, instructor profiles |
| Salon/Beauty | Service menu, before/after photos, booking |
| Real Estate | Property listings, area guides, agent profiles |
