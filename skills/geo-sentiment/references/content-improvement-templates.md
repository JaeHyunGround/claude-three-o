# Content Improvement Templates

## Template Selection Logic

Based on sentiment gap analysis, select appropriate content fix:

| Issue | Template | Priority |
|-------|----------|----------|
| Outdated information | Fresh Content Push | Critical |
| Missing differentiator | USP Highlight Page | High |
| Factual error in AI | Authoritative Correction | Critical |
| Competitor dominance | Comparison Content | High |
| Generic/vague mention | Structured Data Enhancement | Medium |
| Negative sentiment | Reputation Content | High |

## Template 1: Fresh Content Push

**When:** AI cites outdated information (old pricing, discontinued features)

Actions:
1. Update primary website with current information
2. Publish dated press release or blog post with new data
3. Ensure Schema.org dateModified is current
4. Submit to IndexNow for fast re-crawl
5. Create structured FAQ with updated answers

## Template 2: USP Highlight Page

**When:** Brand mentioned but without key differentiators

Actions:
1. Create dedicated comparison/about page with unique value props
2. Use bullet-point format (AI-friendly for extraction)
3. Include quantified claims ("50% faster", "10,000+ customers")
4. Add testimonials with specific results
5. Mark up with Schema.org (Product, Review, AggregateRating)

## Template 3: Authoritative Correction

**When:** AI makes factually incorrect claims about brand

Actions:
1. Identify claim source (usually outdated web content)
2. Update all owned properties with correct information
3. Publish authoritative correction on primary domain
4. Ensure structured data reflects correct facts
5. Consider Wikipedia/Wikidata correction if applicable

## Template 4: Comparison Content

**When:** Competitors consistently mentioned instead of brand

Actions:
1. Create "[Brand] vs [Competitor]" content pages
2. Include objective comparison tables
3. Acknowledge competitor strengths (builds AI trust)
4. Highlight specific advantages with evidence
5. Target comparison query variants in both Korean and English

## Template 5: Structured Data Enhancement

**When:** Brand mentioned generically without specific attributes

Actions:
1. Add comprehensive Schema.org markup (Organization, Product, Service)
2. Include specific attributes: priceRange, areaServed, openingHours
3. Add sameAs links to all official profiles
4. Ensure review/rating data is marked up
5. Add FAQ schema where appropriate (healthcare/government only)

## Template 6: Reputation Content

**When:** AI mentions brand with negative sentiment

Actions:
1. Identify specific criticism themes
2. Create response content addressing each concern
3. Publish case studies showing improvement/resolution
4. Encourage fresh positive reviews on indexed platforms
5. Build authority content establishing expertise (E-E-A-T signals)

## Implementation Priority

Score each action: `impact × feasibility × urgency`
- Impact: How much will this improve AI mentions (1-5)
- Feasibility: How quickly can this be done (1-5, 5=fastest)
- Urgency: How much is current state hurting (1-5)
