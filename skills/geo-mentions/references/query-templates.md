# Industry-Specific Query Templates

## Template Variables
- `{brand}` — Brand name
- `{category}` — Product/service category
- `{location}` — Target location
- `{competitor}` — Known competitor name

## Universal Queries (All Industries)
1. "best {category} in {location}"
2. "{category} recommendations"
3. "{brand} review"
4. "{brand} vs {competitor}"
5. "top {category} companies"
6. "is {brand} good"
7. "{category} comparison"
