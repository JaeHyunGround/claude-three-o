# Gap Analysis Methodology

## Opportunity Scoring

Each keyword gap is scored by:

```
Opportunity Score = Search Volume × (1 / Difficulty) × Intent Value × Engine Multiplier
```

| Factor | Calculation |
|--------|-------------|
| Search Volume | Monthly searches (normalized 0-100) |
| Difficulty | 1-100 scale, inverted for scoring |
| Intent Value | Informational: 1x, Commercial: 2x, Transactional: 3x |
| Engine Multiplier | Google only: 1x, Naver only: 1x, Both: 1.5x |

## Priority Matrix

| Quadrant | Volume | Difficulty | Action |
|----------|--------|------------|--------|
| Quick Wins | Medium+ | Low | Create content immediately |
| Strategic | High | High | Plan long-term content strategy |
| Fill Gaps | Low | Low | Batch create when resources allow |
| Monitor | Low | High | Watch but don't prioritize |

## Content Coverage Scoring

| Coverage Level | Definition |
|----------------|------------|
| Full | Dedicated page with 800+ words / 1600+ Korean chars |
| Partial | Mentioned in a page but not primary topic |
| Missing | No relevant content exists |

## Cross-Engine Analysis

Track where each site ranks per engine:
- **Both engines**: Strong competitive position
- **Google only**: Naver platform content needed (Blog, Place)
- **Naver only**: Website SEO improvements needed
- **Neither**: New opportunity for first mover
